# hanabi-convention-gap

Code, data, and reproduction package for:

> **The Convention Gap: Towards Measuring Implicit Communication in
> Cooperative AI Evaluation**
> Makoto Fukushima (Honda Research Institute Japan),
> Hua-Dong Xiong (Honda Research Institute USA),
> Ehsan Moradi Pari (Honda Research Institute USA)

Archived at **doi:10.5281/zenodo.21975884** — the DOI resolves to the frozen
release of this repository.

The *convention gap* is the difference between an exactly computable
literal-information posterior probability of failure and the actual failure
rate: performance unexplained by the literal content of communication. In
Hanabi the posterior is exact — a full-hand joint enumeration with
without-replacement weights, no sampling, no fitted parameters.

## What is here

```
convention_gap/   The metric as an installable package (pure stdlib, pip install .)
src/              The paper's full reproduction pipeline (replay engines, corpus
                  loaders, cluster statistics, analysis and figures)
tests/            168 pipeline tests + the package's own test suite (test_pkg_*)
notebooks/        reproduce_paper_figures_v9.ipynb — regenerates every figure,
                  table, and statistic in the paper from data/processed/
data/processed/   Pseudonymized per-play record datasets (see LICENSE-DATA),
                  incl. llm_joint_posteriors.csv, llm_per_condition_tables.md,
                  llm_corpus_manifest.md, llm_fallback_counts.json
data/raw/         Bundled public game logs (HOAD; HanabiData converted).
                  Raw hanab.live logs are not shipped (they contain plaintext
                  usernames); refetch by game id via the public API.
obl/              Off-belief-learning validation: derived result JSONs,
                  generation/verification scripts, license audit. No game
                  logs, no checkpoints — see obl/NOTICE.
output/           Figures and the quantitative-changes ledger
REPRODUCING.md    Detailed reproduction guide (corpus definitions, privacy,
                  regeneration commands)
```

## Install the metric package

```bash
pip install .          # installs the `convention_gap` package (no dependencies)
python -m pytest tests/test_pkg_*.py -q
```

```python
from convention_gap.replay import replay_and_extract
from convention_gap.gap import convention_gap, cluster_bootstrap_gap_ci
records, final_state = replay_and_extract(game_json)  # hanab.live-format game
result = convention_gap(records)                       # dict: gap (joint posterior), mean posterior, loss rate, n
```

## Reproduce the paper

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt        # pinned; verified on Python 3.13
python -m pytest tests/ -q             # full test suite
jupyter nbconvert --to notebook --execute notebooks/reproduce_paper_figures_v9.ipynb
```

Every number in the paper is generated by this pipeline; the ledger
`output/numbers_diff_v5_to_v7.md` records the version-to-version numeric
history including the v9 (joint-posterior-primary) recompute.

The OBL validation appendix is reproduced from `obl/gap_results.json` /
`obl/gap_interlevel.json`; regenerating those from scratch requires a local
build of the [off-belief-learning](https://github.com/facebookresearch/off-belief-learning)
codebase and its released checkpoints (see `obl/NOTICE` and the scripts in
`obl/`).

## Data source attributions

- **hanab.live** (https://hanab.live) — public human-human game replays,
  accessed via the public API; usernames pseudonymized with salted 16-hex
  hashes (the 13 verified bot-family accounts keep their public names).
- **HOAD** — Hanabi Open Agent Dataset (Sarkar et al., 2023), agent-vs-agent
  games; agents re-implemented from Walton-Rivers et al. (2017),
  Van den Bergh (2015), Osawa (2015).
- **HanabiData** (Eger et al., 2017; https://github.com/yawgmoth/HanabiData)
  — human-vs-AI games; participant consent obtained in the original study.
- **Off-Belief Learning** (Hu et al., ICML 2021;
  https://github.com/facebookresearch/off-belief-learning) — released
  checkpoints used to generate the validation games; code and checkpoints
  © Facebook, Inc. and affiliates, CC BY-NC 4.0, not redistributed here.
